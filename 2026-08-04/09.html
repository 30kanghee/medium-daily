Data Scientist vs ML Engineer vs MLOps Engineer

Manoj Saini · 4 min read · 원문 보기 (Medium)

요약

세 직함, 세 가지 다른 삶 — 모델을 만드는 사람인가, 돌리는 사람인가, 지키는 사람인가.

채용 공고마다 데이터 사이언티스트, ML 엔지니어, MLOps 엔지니어라는 직함이 뒤섞여 등장하지만 실제로 하는 일은 꽤 다르다는 게 이 글의 출발점이다. 데이터 사이언티스트는 데이터를 탐색하고 모델과 알고리즘을 실험하며 인사이트를 뽑아내는 데 집중한다. ML 엔지니어는 그렇게 만들어진 모델을 실제 서비스에서 돌아가도록 최적화하고 학습 파이프라인을 구축하는 역할을 맡는다. MLOps 엔지니어는 모델이 배포된 이후 안정적으로 운영되도록 모니터링하고 CI/CD 파이프라인을 관리하는, 조금 더 인프라에 가까운 업무를 담당한다. 저자는 이 세 역할이 서로 경쟁 관계가 아니라 연구와 엔지니어링을 잇는 협업 구조라는 점을 강조하며, 직함에 헷갈려하지 말고 각자의 역할을 이해하라고 조언한다.
