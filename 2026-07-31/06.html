요약

실제 데이터 엔지니어링 면접에서 나온 중급 난이도 SQL 문제 3가지.

SQL은 기본기만 있으면 될 것 같지만, 데이터 엔지니어링 면접에서는 실무형 사고력을 요구하는 문제가 자주 나온다. 이 글은 실제 면접에서 다뤄질 법한 중급 난이도의 SQL 문제 세 가지를 소개하고, 각 문제를 푸는 접근 방식을 설명하며 구직자들이 준비할 수 있도록 돕는다.
