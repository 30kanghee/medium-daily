System Design Interview: How Would You Let Users Upload Huge Files Even If the Internet Disconnects Midway?

Arvind Kumar · 6 min read
원문 보기 (Medium)

요약

구글 드라이브처럼 업로드 도중 인터넷이 끊겨도 처음부터 다시 올릴 필요 없이 끊긴 지점부터 이어서 올리는 시스템을 어떻게 설계하는지 다룬다.

이 글은 대용량 파일 업로드 중 네트워크가 끊겼을 때 안전하게 이어받기를 구현하는 방법을 묻는 시스템 설계 인터뷰 문제를 풀어나간다. 핵심은 파일을 여러 청크로 쪼개 각각 독립적으로 업로드하고, 이미 성공적으로 전송된 청크는 재전송하지 않는 방식이다. 재연결 시에는 마지막으로 성공한 청크를 다시 해시로 검증해 MD5·SHA-256 같은 체크섬이 서버 측과 일치하는지 확인함으로써 데이터 무결성을 보장한다. 구글 드라이브, 드롭박스, 유튜브, AWS S3 같은 실제 서비스가 이런 청크 기반 재개형 업로드 방식을 쓴다는 점을 예로 들어 설계 과정을 설명한다.
