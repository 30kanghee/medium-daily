Apple Container 1.0 Released: Running Linux Containers on Mac, No More Docker Needed?

Chimin · 4 min read
원문 보기 (Medium)

요약

애플의 container 1.0이 정식 출시되며, 이제 Docker 없이도 맥에서 리눅스 컨테이너를 네이티브로 돌릴 수 있게 됐다.

WWDC 2025에서 처음 공개된 애플의 container 도구가 1년 만인 2026년 6월 정식 1.0 버전으로 출시됐다. Docker Desktop처럼 하나의 거대한 리눅스 VM 안에 모든 컨테이너를 몰아넣는 방식이 아니라, 컨테이너마다 독립된 경량 VM을 macOS의 Virtualization 프레임워크로 띄우는 구조가 핵심이다. Swift로 작성된 vminitd가 VM 초기화를 담당하고 OCI 표준 이미지를 그대로 쓸 수 있어 Docker Hub 이미지도 문제없이 받아온다. 컨테이너별로 VM이 분리돼 있어 탈옥하려면 하이퍼바이저 자체를 뚫어야 하는 만큼 보안 측면에서도 강점을 갖는다.
