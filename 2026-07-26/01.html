Beyond RAG: How Google's Open Knowledge Format (OKF) is Replacing the Vector Database

Secret Dev · The Code Frontier · 5분 읽기 · 원문

구글이 공개한 개방형 지식 포맷(OKF)이 벡터 DB와 임베딩에 의존하던 기존 RAG 방식을 대체할 차세대 AI 지식 저장 표준으로 떠오르고 있다는 이야기.

요약

저자는 지난 3년간 LLM에 최신 정보를 주입하는 표준 방법으로 자리 잡은 RAG(검색 증강 생성) 파이프라인의 한계를 짚는다. 문서를 잘게 쪼개는 청킹 과정에서 표처럼 복잡한 구조가 깨지고, 벡터 검색은 본질적으로 확률에 의존하며, 빠르게 바뀌는 데이터와 임베딩을 계속 동기화하는 것도 운영 부담이 크다는 것이다. 이에 대한 대안으로 구글 클라우드가 공개한 OKF(Open Knowledge Format) v0.1을 소개하는데, 이는 특정 벤더에 종속되지 않는 개방형 명세로 흩어진 정보를 검색 가능한 조각이 아니라 서로 연결된 하나의 지식 체계로 정리하자는 아이디어에 가깝다. 즉 벡터 데이터베이스나 별도의 LLM 프레임워크가 아니라, AI가 참조할 지식 자체의 구조를 표준화하려는 시도라는 점을 강조한다.
