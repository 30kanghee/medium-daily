AI-Generated Architecture Diagrams in VS Code Using Draw.io MCP

Manoj Saini · 4 min read
원문 보기 (Medium)

요약

이제 아키텍처 다이어그램도 말로 설명하면 AI가 VS Code 안에서 바로 수정 가능한 draw.io 파일로 그려준다.

MCP(Model Context Protocol)를 통해 AI 어시스턴트가 로컬 도구와 안전하게 연동되면서, 단순 코드 자동완성을 넘어 실제 개발 파트너 역할을 하기 시작했다. 이 글은 draw.io MCP 서버를 VS Code에 연결해, 자연어로 인프라나 시스템 구조를 설명하면 AI가 곧바로 다이어그램용 XML을 생성해주는 방법을 소개한다. 가장 큰 장점은 브라우저와 IDE를 오가며 이미지를 내보내고 다시 가져오는 번거로움 없이 에디터 안에서 바로 결과를 확인할 수 있다는 점이다. 게다가 결과물이 정적 이미지가 아니라 편집 가능한 파일로 나오기 때문에 필요할 때 언제든 손으로 다듬을 수 있어, 글 후반부에는 이 MCP 서버를 실제로 설정하는 과정을 단계별로 안내한다.
